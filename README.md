# 공간 3D 만들기

벽·바닥·가구를 놓아 보며 공간을 3D로 먼저 그려 보는 웹 프로그램입니다.
설치 없이 브라우저에서 `index.html`만 열면 됩니다(인터넷 연결 불필요).

## 할 수 있는 것

- **벽 그리기**: 바닥을 두 번 눌러 벽을 세우고, 이어서 계속 그리기
- **추가**: 벽, 바닥, 상자, 원기둥
- **크기·위치·회전**: 오른쪽 패널에서 미터 단위로 입력, 선택한 물체는 끌어서 이동
- **색·투명도**: 색 고르기와 빠른 색 단추
- **보기**: 입체 / 위에서, 끌어서 화면 돌리기, 휠로 확대·축소
- **되돌리기 / 다시 실행**, 복제, 삭제
- **저장**: 브라우저에 자동 저장, 파일(JSON)로 내보내기·불러오기

## 단축키

| 키 | 동작 |
| --- | --- |
| `W` | 벽 그리기 켜기/끄기 |
| `Esc` | 벽 그리기 끝내기 / 선택 해제 |
| 방향키 | 선택한 물체를 격자 한 칸씩 이동 |
| `Delete` | 삭제 |
| `Ctrl+D` | 복제 |
| `Ctrl+Z` / `Ctrl+Y` | 되돌리기 / 다시 실행 |

## 실행

파일을 직접 열면 브라우저 보안 정책 때문에 스크립트가 막힐 수 있으니, 간단한 서버로 여는 것이 안전합니다.

```bash
npx serve .
```

GitHub Pages에 올리면 그대로 동작합니다.
