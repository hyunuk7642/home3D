# 공간 3D 만들기

벽·바닥·가구를 놓아 보며 공간을 3D로 먼저 그려 보는 웹 프로그램입니다.
설치 없이 `index.html`을 더블클릭하면 브라우저에서 바로 열립니다(인터넷 연결 불필요).

## 할 수 있는 것

- **벽 그리기**: 바닥을 두 번 눌러 벽을 세우고, 이어서 계속 그리기
- **문·창문**: 벽을 고르고 "문"이나 "창문"을 누르면 그 벽이 뚫리며 달립니다. 끌어서 다른 벽으로 옮길 수 있고, 벽을 옮기면 함께 따라갑니다
- **추가**: 벽, 문, 창문, 바닥, 상자, 원기둥
- **크기·위치·회전**: 오른쪽 패널에서 미터 단위로 입력, 선택한 물체는 끌어서 이동
- **색·투명도**: 색 고르기와 빠른 색 단추
- **보기**: 입체 / 위에서, 끌어서 화면 돌리기, 휠로 확대·축소
- **되돌리기 / 다시 실행**, 복제, 삭제
- **저장**: 브라우저에 자동 저장, 파일(JSON)로 내보내기·불러오기

## 맥북에서 쓰기

`index.html`을 더블클릭하면 사파리나 크롬에서 바로 열립니다. 서버나 설치가 필요 없습니다.

맥에서는 위쪽의 **트랙패드**가 자동으로 켜집니다.

| 트랙패드 동작 | 결과 |
| --- | --- |
| 두 손가락으로 쓸기 | 화면 돌리기 |
| 두 손가락 벌리기 / 오므리기 | 확대 / 축소 |
| `Shift` + 두 손가락으로 쓸기 | 화면 옮기기 |
| 물체를 누르기 | 선택 |
| 선택한 물체를 누른 채 끌기 | 물체 옮기기 |

마우스를 연결해 휠로 확대·축소하고 싶으면 **트랙패드** 체크를 끄면 됩니다.

## 단축키

맥 기준입니다. 윈도우에서는 `⌘` 대신 `Ctrl`을 씁니다.

| 키 | 동작 |
| --- | --- |
| `W` | 벽 그리기 켜기/끄기 |
| `Esc` | 벽 그리기 끝내기 / 선택 해제 |
| 방향키 | 선택한 물체를 격자 한 칸씩 이동 |
| `⌫` (delete) | 삭제 |
| `⌘D` | 복제 |
| `⌘Z` / `⇧⌘Z` | 되돌리기 / 다시 실행 |

## 구성

- `index.html`, `style.css`, `app.js` — 프로그램 본체
- `vendor/three.bundle.js` — [three.js](https://threejs.org) r170과 OrbitControls를 한 파일로 묶은 것 (MIT 라이선스)
