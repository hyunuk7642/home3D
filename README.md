# 공간 3D 만들기

벽·바닥·가구를 놓아 보며 공간을 3D로 먼저 그려 보는 웹 프로그램입니다.
설치 없이 `index.html`을 더블클릭하면 브라우저에서 바로 열립니다(인터넷 연결 불필요).

## 할 수 있는 것

- **벽 그리기**: 바닥을 두 번 눌러 벽을 세우고, 이어서 계속 그리기
- **문·창문**: 벽을 고르고 "문"이나 "창문"을 누르면 그 벽이 뚫리며 달립니다. 끌어서 다른 벽으로 옮길 수 있고, 벽을 옮기면 함께 따라갑니다
- **추가**: 벽, 문, 창문, 바닥, 상자, 원기둥, 원뿔, 공, 전구 줄, 리스, 사람
- **크기·위치·회전**: 오른쪽 패널에서 미터 단위로 입력, 선택한 물체는 끌어서 이동
- **색·투명도**: 색 고르기와 빠른 색 단추
- **보기**: 입체 / 위에서, 끌어서 화면 돌리기, 휠로 확대·축소
- **묶음**: 트리처럼 여러 조각으로 된 것은 끌면 함께 움직이고, "묶음 풀기"로 따로 다룰 수 있습니다
- **전시 공간**: 10 × 8 m 방(앞쪽은 유리벽)에 다섯 전시관을 배치합니다. 벽면 하나가 전시관 하나이고(왼쪽 벽, 가벽 앞면, 가벽 뒷면, 뒤쪽 벽, 오른쪽 벽), 빈 전시판 자리 26곳과 상자 트리 2그루, 이동식 화면 3대, 이야기 자리가 놓입니다
- **전시 자료 배치**: 전시 「스무 개의 질문」의 서문, 관 소개, 연구회 20곳의 글·그림을 전시판에 입힙니다. 다시 누르면 뺍니다. 교사 이름은 OOO으로 가려져 있습니다
- **크리스마스 꾸미기**: 전시 공간에 카펫(복도 레드카펫, 초록 카펫, 둥근 카펫), 전구 줄, 리스, 작은 트리, 장식 공, 지팡이 사탕 기둥, 선물 더미, 눈사람을 한 번에 놓습니다. 다시 누르면 꾸민 것만 뺍니다. "추가"의 원뿔·공·전구 줄·리스로 직접 더 꾸밀 수도 있습니다
- **걸어 보기**: 사람의 눈높이(키 1.7 m면 1.6 m)에서 걸어 다니며 공간을 봅니다. `W A S D`·방향키로 걷고 돌고, 끌어서 둘러보고, 트랙패드는 두 손가락 쓸기로 걷습니다. 벽과 가구는 통과하지 못하고 문으로는 지나갑니다. "사람"을 먼저 놓으면 그 자리에서 시작하고, 끝내면 사람이 걸어간 자리에 남습니다
- **되돌리기 / 다시 실행**, 복제, 삭제
- **저장**: 브라우저에 자동 저장, 파일(JSON)로 내보내기·불러오기

## 맥북에서 쓰기

`index.html`을 더블클릭하면 사파리나 크롬에서 바로 열립니다. 서버나 설치가 필요 없습니다.

맥에서는 위쪽의 **트랙패드**가 자동으로 켜집니다.

| 트랙패드 동작 | 결과 |
| --- | --- |
| 두 손가락으로 쓸기 | 화면 돌리기 |
| 두 손가락 벌리기 / 오므리기 | 확대 / 축소 |
| `Shift` + 두 손가락으로 쓸기 | 화면 옮기기 |
| 물체를 누르기 | 선택 |
| 선택한 물체를 누른 채 끌기 | 물체 옮기기 |

마우스를 연결해 휠로 확대·축소하고 싶으면 **트랙패드** 체크를 끄면 됩니다.

## 단축키

맥 기준입니다. 윈도우에서는 `⌘` 대신 `Ctrl`을 씁니다.

| 키 | 동작 |
| --- | --- |
| `W` | 벽 그리기 켜기/끄기 |
| `Esc` | 벽 그리기 끝내기 / 선택 해제 |
| 방향키 | 선택한 물체를 격자 한 칸씩 이동 |
| `⌫` (delete) | 삭제 |
| `⌘D` | 복제 |
| `⌘Z` / `⇧⌘Z` | 되돌리기 / 다시 실행 |

## 구성

- `index.html`, `style.css`, `app.js` — 프로그램 본체
- `posters.js` — 전시 벽면에 입히는 그림 26장(서문, 관 소개, 연구회)
- `vendor/three.bundle.js` — [three.js](https://threejs.org) r170과 OrbitControls를 한 파일로 묶은 것 (MIT 라이선스)
